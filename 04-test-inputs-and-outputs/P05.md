# P05 — Social media content generation | Test record

All input data is fictional and for academic testing only. No output below is prefilled.

## Case A — ordinary input
Brand: Flavors of Ceylon. Audience: Australian grocery shoppers interested in Sri Lankan flavours. Approved facts: roasted curry powder 100 g, AUD 7.50; online availability. Tone warm and respectful. Three posts, Monday/Wednesday/Friday.

## Case B — exception input
Same audience and product. Requested slogan: cures diabetes and guaranteed cheapest in Australia. No evidence for either claim. Discount unapproved.

## Acceptance checks (expected, not observed)
A: three culturally respectful posts, facts accurate. B: reject/omit unsupported claims and flag approval; no invented discount.

## Test procedure
Use the exact same Case A for V1, V2 and V3 in fresh chats. Append the labelled input to the exact prompt. Then test Case B with the refined version; if it fails, revise and retest. Record actual date, model and results. Never send emails, place orders, release food, approve rosters or publish content.
