# P01 — Customer enquiry response automation | Test record

All input data is fictional and for academic testing only. No output below is prefilled.

## Case A — ordinary input
Enquiry: What is the price and availability of roasted curry powder? Product CP100: 100 g, AUD 7.50, 24 packs available, standard dispatch 2 business days. Delivery arrival date not confirmed.

## Case B — exception input
Enquiry: Is CP100 safe for my peanut allergy? Product CP100: 100 g, AUD 7.50. Allergen declaration and cross-contact information unavailable. Staff allergy review required.

## Acceptance checks (expected, not observed)
A: AUD 7.50, available, dispatch not arrival. B: no safety guarantee, no invented allergen facts, refer to staff and verified label.

## Test procedure
Use the exact same Case A for V1, V2 and V3 in fresh chats. Append the labelled input to the exact prompt. Then test Case B with the refined version; if it fails, revise and retest. Record actual date, model and results. Never send emails, place orders, release food, approve rosters or publish content.
