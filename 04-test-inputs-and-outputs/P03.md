# P10 — Weekly business performance reporting | Test record

All input data is fictional and for academic testing only. No output below is prefilled.

## Case A — ordinary input
Verified weekly metrics: sales AUD 4,500 vs prior AUD 4,000; units produced 520 vs 500; waste 20 vs 15 units; complaints 6 vs 4. Spreadsheet change sales +12.5%. Labour cost not provided.

## Case B — exception input
Sales sheet AUD 4,500; finance sheet AUD 4,050 for same week; waste missing; complaints 6. Prior week unavailable. Labour cost missing.

## Acceptance checks (expected, not observed)
A: report sales +12.5%, rising waste and complaints, no profit claim. B: flag sales conflict, missing comparators and waste; do not select arbitrary sales total.

## Test procedure
Use the exact same Case A for V1, V2 and V3 in fresh chats. Append the labelled input to the exact prompt. Then test Case B with the refined version; if it fails, revise and retest. Record actual date, model and results. Never send emails, place orders, release food, approve rosters or publish content.
