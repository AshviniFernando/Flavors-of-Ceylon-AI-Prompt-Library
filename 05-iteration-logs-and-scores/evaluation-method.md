# Evaluation method
Score each category 1–5 (1 = fails, 3 = partially meets, 5 = meets consistently for this run). Sum to /25. Accuracy = matches verified input; completeness = required facts; format = useful readable output; constraints = obeys task restrictions; safety = escalation and approval. A critical failure overrides a high score. Compare V1–V3 with the same input and tool where possible; report variability and small sample limitations. Do not claim statistical or real-world performance from fictional tests. Track time including verification and edits, not model latency alone. Compare with a manual draft of the same task if claiming time savings. Record actual findings and source links.

## Impact metrics
Customer enquiry handling time, first-draft acceptance, stock alert accuracy, forecast error (when actual sales become available), roster conflict count, safety escalation accuracy, reporting preparation time. Targets are proposed, not achieved.
